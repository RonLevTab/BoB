## How the issue tracker works

- **Milestone** = assessment: `Boostcamp`, `Team up for Business`, `My Drive`, `My Dream`.
- **`type:*`** (exactly one per issue): deliverable, research, evidence, reflection, event, build, admin.
- **`rubric:*`** (one or more): the grading indicator this issue produces evidence for. Taken verbatim from the rubrics.
- **`ilo:*`**: the intended learning outcome behind the rubric line.
- **`phase:*`**: inspiration / ideation / implementation (Tim Brown cycle, mainly My Dream).
- **`status:*`** and **`priority:critical`**: blocked, needs review, waiting on someone, or fail-if-missed.

An issue is only closed when its evidence is attached: a file path in this repo,
a Brightspace submission screenshot, a photo, a CSV, or a certificate. Group work
is logged as *my* contribution with a link to the shared team file.
